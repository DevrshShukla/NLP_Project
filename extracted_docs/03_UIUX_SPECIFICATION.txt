1. Design Principles
  Readability over effects. This is a study tool: text contrast, spacing and hierarchy come first.
 Modern, minimal, student-friendly. Gen-Z inspired but not childish: soft gradients, rounded
cards, restrained glass effects.
 Priority at a glance. HIGH / MEDIUM / LOW is always conveyed by label + icon + color, never color
alone.
 Fast and calm. Immediate feedback, honest progress states, no surprise modals.
 Dark-first, light-complete. Default follows system preference; both themes are first-class and
use identical tokens.

5. Global UX States
State
Behavior
Loading
Skeletons for lists and cards. Stage-based progress for analysis. Buttons show spinner and are
disabled while busy.
Empty
Explains why it is empty and offers the next action. Example: no topics found suggests
providing more text with clear headings.
Error
Uses catalog messages (see Technical Requirements). Never shows stack traces. Offers Retry
and, where useful, guidance.
Warning banner
Non-blocking notice (for example LOW_EXTRACTION_QUALITY or low language confidence),
dismissible.
Offline
Toast: You appear to be offline. Retry when connected.
Long operation
After 15 s show: Large documents can take longer. Phase 2 offers to continue in the
background.

8. Accessibility Specification
  Standard: WCAG 2.2 AA.
 Keyboard: all functionality reachable by keyboard; logical tab order; visible 2 px focus ring; arrow
keys inside tabs and segmented controls; Escape closes drawers and modals.
 Contrast: text >= 4.5:1, large text and UI components >= 3:1, verified for both themes.
 Priority not by color alone: label + icon + position in list.
 Screen readers: semantic landmarks (header, nav, main, footer), headings in order, labels on all
inputs, aria-live=polite for processing progress, aria-busy on loading regions.
 Forms: errors linked with aria-describedby; error summary focus after failed submit.
 Graph: provide equivalent nested list; nodes focusable; selection announced.
 Motion: respect prefers-reduced-motion; no auto-playing animation longer than 5 s.
 Charts: each chart has a data table alternative and text summary.

9. Acceptance Criteria
 1. All twelve pages implement listed states and responsive behavior (Phase 2 pages when in scope).
2. Light and dark themes use identical tokens with values above; no hard-coded colors in
