3. Text Input
Feature ID: F01 Phase: MVP
Aspect
Specification
Objective
Let users paste or type study material for analysis.
User value
Zero-friction start without needing a file.
User flow
Open Analyze > Paste Text tab > enter text (optional title) > Extract Topics.
Inputs
text (200 to 150,000 chars), title (optional, max 120 chars)
Outputs
Validated payload sent to analysis.
Backend requirements
POST /api/analyze validates length, strips control characters, normalizes Unicode (NFKC).
Frontend
requirements
Textarea with live counter, clear button, sample-text button, disabled state while busy.
Database
requirements
None in MVP. P2: documents row (source_type=text) when save=true.
Edge cases
Only whitespace; emoji/RTL text; pasted HTML (tags stripped); 1 MB clipboard paste.
Error states
TEXT_TOO_SHORT, DOCUMENT_TOO_LARGE, INVALID_REQUEST.
Acceptance criteria
Button enabled only within bounds; counter accurate; sample text produces results in < 3 s.

Analyze > Upload PDF > drop/select file > validation > extraction preview.

Non-PDFs rejected client and server side; valid PDF proceeds; no file written to disk in MVP.
5. PDF Text Extraction
Feature ID: F03 Phase: MVP
Aspect
Specification
Objective
Convert PDF pages into clean text with page mapping.
User value
Reliable input for NLP.
User flow
Automatic after upload validation.
Inputs
PDF bytes
Outputs
text, page_count, quality (0-1), warnings, page offsets.
Backend requirements
pdf_processor.py with PyMuPDF page.get_text("text", sort=True); hyphenation repair;
header/footer removal; page limit 200.
Frontend
requirements
Preview panel (first 2,000 chars) and quality alert.
Database
requirements
P2: documents.extracted_text, page_count, extraction_quality,
extraction_method=native.
Edge cases
Multi-column layouts; tables; footnotes; ligatures; encrypted; corrupted; tiny text layer.
Error states
PASSWORD_PROTECTED_PDF, NO_READABLE_TEXT, DOCUMENT_TOO_LARGE, INVALID_PDF.
Acceptance criteria
Text-based 50-page PDF extracts in < 5 s; quality reported; encrypted PDFs give correct error.

back to original text.

9. N-gram Extraction
Feature ID: F07 Phase: MVP
Aspect
Specification
Objective
Generate unigram, bigram and trigram candidates and prefer meaningful phrases.
User value
Captures concepts like support vector machine.
User flow
Internal stage.
Inputs
Lemmatized tokens with POS
Outputs
Candidate list with counts, positions, n-gram size.
Backend requirements
ngram_extractor.py: POS pattern (ADJ|NOUN)* NOUN; edge stopword filter; min count 2 for
n >= 2 unless in heading/definition; NPMI >= 0.1; subsumption rule.
Frontend
requirements
None.
Database
requirements
None.
Edge cases
Overlapping phrases; acronyms (SVM); capitalized proper nouns; hyphenation.
Error states
-
Acceptance criteria
support vector machine appears as one trigram topic; machine and learning alone are
suppressed when they occur almost always inside machine learning.
